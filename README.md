# Number Guessing Game (C++)

## Description
A simple console-based Number Guessing Game developed in C++ as part of my C/C++ Development Internship at Auspify Technologies.

The program generates a random number between 1 and 100, and the player must guess the number using hints provided by the game.

## Features
- Random number generation
- Hints for guesses that are too high or too low
- Attempt counter
- Input validation for non-numeric input
- Displays the correct number and total attempts when the player wins

## Technologies Used
- C++
- Standard Library (`random`, `chrono`, `iostream`)

## How to Run

1. Compile the program:

   ```bash
   g++ cpp_guessing_game.cpp -o guessing
   ```

2. Run the game:

   **Windows:**
   ```powershell
   .\guessing
   ```

## How to Play
1. Run the program.
2. Enter a number between 1 and 100.
3. Follow the hints to guess the secret number.
4. Keep guessing until you find the correct number.
5. The game displays your total attempts.
